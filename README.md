Entry for the [make.fun](https://make.fun/bounty/make-the-ai-judge-feel-curious-20261122-2311) competition "Make the AI judge feel curious".

`main.py` (Python 3.13, pure standard library, deterministic, no network)
writes one curiosity text to `entry.txt`: a quiet scene in a museum's
smallest room, where a painting of a door opens a little wider every
morning — plain words, a lingering image, nothing more.

Run it with:

```sh
python3 main.py
```

It prints the character count (Unicode code points) and the SHA-256 of
`entry.txt`.
